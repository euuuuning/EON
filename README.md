# EON

1. 프로젝트 개요
•	프로젝트명: 전기차 토탈 관리 플랫폼 (Eon)
•	목적:
전기차 구매·관리·운행에 필요한 핵심 정보를 웹 하나에서 제공 
•	개발 기간 : 6주 (MVP 범위)
•	개발 방식 : Web App (모바일·PC 반응형)
•	주요 타깃:
1)	성남시 전기차 보유자
2)	전기차 구매 예정자
3)	전기차 관련 정책 및 인프라 담당 공공기관

2. 개발 배경 및 필요성
•	전기차 보조금 정책과 충전소 정보가 정부·지자체·민간 플랫폼에 각각 흩어져 있어 사용자 불편 초래
•	실시간 충전소 점유 상태, 요금, 충전 타입까지 한 번에 제공하는 플랫폼 부재
•	성남시 한정 MVP로 시작 → 경기·서울 등으로 확장 가능성 확보

3. MVP 범위
1) 사용자의 위치 기반으로 전기차 충전소를 찾고, 충전기의 스펙을 제공
2) 성남시 기준으로 정부 및 지자체의 전기차 보조금 정보를 제공
3) 사용자 친화적인 UI/UX 설계해, 누구나 쉽게 접근할 수 있도록 함.
4) 전 과정을 웹 하나로 담아 ‘켜는 순간 시작되는 EV 라이프’를 목표
