# EON
 밝은 전기차 시대의 도래를 기대하며, 저희 팀은 **‘전기차 보조금’**과 **‘전기차 충전소 및 충전기’**라는 두 가지 핵심 기능에 집중하였습니다. 
 ‘전기차 보조금’ 조회 기능은 전기차 구매 전 이용자들이 특히 관심을 가질 만한 서비스로, *“내가 놓치고 있는 보조금은 무엇일까?”*라는 질문에 답하며 보다 합리적인 구매 결정을 돕습니다. 한편, ‘전기차 충전소 및 충전기’ 조회 기능은 전기차 구매 후 이용자들의 차량 관리와 충전 편의성을 높이는 데 초점을 맞추었습니다. 
 저희 팀은 이 두 기능을 전기차 시대의 실질적인 사용자 니즈로 정의하고, 이를 구현하기 위해 본격적인 개발에 착수하였습니다.
